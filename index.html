Comment ça marche

Télécharger MOTSA Desktop
01

Détection locale des PDFs

L'agent MOTSA lit votre historique Chrome directement sur votre machine. Aucun fichier ne quitte votre ordinateur à cette étape.

02

Empreinte SHA-256 calculée chez vous

Le hash cryptographique est calculé localement par l'agent. Seule cette empreinte — et non le PDF — est transmise à nos serveurs.

03

Certificat généré côté serveur

Notre serveur crée la page certificat avec QR code à partir du hash. Le PDF certifié vous est renvoyé directement pour téléchargement.

04

Seul le hash est stocké

Nous n'enregistrons jamais votre PDF. Uniquement son empreinte SHA-256 — à sens unique, irréversible. Le contenu de vos documents reste confidentiel.

05

Vérification publique sans compte

N'importe qui peut scanner le QR code ou déposer le PDF certifié sur motsa.tech pour confirmer son authenticité — le hash est recalculé localement dans le navigateur.

06

Traçabilité complète

Source URL, date de téléchargement, identité du titulaire — chaque métadonnée est liée au certificat et consultable publiquement via le token de vérification.

Vos fichiers ne quittent jamais votre machine

MOTSA ne stocke ni ne transmet vos PDFs. Seule l'empreinte SHA-256 — mathématiquement irréversible — est enregistrée dans notre base. Il est impossible de retrouver votre document à partir de son hash.
