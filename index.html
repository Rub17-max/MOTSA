How it works

Two API calls. Absolute trust.

01 — Certify

Issuer API

The university sends document metadata and the SHA-256 hash of the PDF. MOTSA returns a certificate ID and a permanent verification URL.

02 — Verify

Verification API

The HR team uploads the received PDF. MOTSA recomputes the hash locally and compares it to the certified version — nothing is ever uploaded.

03 — Result

Clear outcome

No vague scores. The result is Verified, Modified, or Unknown — with full issuer and holder details.
