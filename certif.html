Certify interface — Issuer

Certify an official document

This interface simulates the issuer portal. The PDF hash is computed locally in your browser — the file is never uploaded. MOTSA stores only the hash and metadata.

New certificate

POST /api/v1/certificates
Authorization: Bearer <API_KEY>

}
Certified

Certificate created

The document is now registered with its official issuer. Share the certificate ID with the holder so they can include it in applications.

Error
